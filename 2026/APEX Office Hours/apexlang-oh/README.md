# APEX Streaming

Demostración de Oracle APEX + APEXlang + Codex.

## Objetivo

Crear una aplicación Oracle APEX desde cero utilizando APEXlang
como lenguaje de definición de la aplicación y Codex como agente
de desarrollo.

## Arquitectura

Codex
  ↓
APEX Skills
  ↓
APEXlang
  ↓
SQLcl
  ↓
Oracle Database 26ai
  ↓
Oracle APEX 26.1

## Aplicación

APEX Streaming permite administrar:

- Géneros
- Películas
- Actores
- Clientes
- Alquileres
- Estadísticas
- Dashboard

## Entorno

- Windows
- VS Code
- Git
- Codex
- SQLcl 26.1+
- Oracle Database 26ai
- Oracle APEX 26.1
